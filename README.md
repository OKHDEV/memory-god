# 🧠 암기의 신 (Memory God)
> **"어떤 긴 글도 100% 확실하게 외워지는 뇌과학 기반 5단계 점진적 암기 시스템"**  
> 💥 **찰진 타격감 사운드와 시각 효과로 뇌에 팡팡 각인되는 최고의 암기 웹 애플리케이션**

---

## 🌟 핵심 특징

1. **뇌과학 기반 5단계 마스터리 시스템 (Scientific 5-Step Pipeline)**
   - **STEP 1 (낭독 & 쉐도잉)**: TTS 원어민 발음(속도 조절 0.7x ~ 1.2x)을 들으며 소리와 문맥을 귀와 입에 각인.
   - **STEP 2 (점진적 빈칸 뚫기)**: 25% → 50% → 75% → 100% 난이도 조절. 빈칸을 클릭하면 팡! 소리와 함께 정답 확인.
   - **STEP 3 (초성 / 첫 글자 단서 훈련)**: 한국어 초성(`ㅇㄱㅎ ㅇㅅㅇ...`) 및 영문 첫 글자(`Y___ t___ i_...`) 단서만 보고 머릿속에서 전체 문장을 인출(Active Recall)하는 최고의 두뇌 훈련.
   - **STEP 4 (배우 대본식 누적 체이닝)**: 1번 문장 → 1+2번 문장 → 1+2+3번 문장... 긴 장문의 앞뒤 연결고리를 체인처럼 머리에 결속시키는 연기자/성우들의 절대 암기법.
   - **STEP 5 (고스트 블라인드 타자 & 음성 구술)**: 화면이 가려진 상태에서 타이핑! 칠 때마다 실시간으로 맞춘 글자가 나타나며, 마이크로 말해서 맞히는 음성 구술(STT) 지원!

2. **💥 찰진 타격감 사운드 & 비주얼 이펙트 (Juicy Gamification)**
   - **Web Audio API 합성 사운드**: 글자 칠 때마다 찰칵거리는 기계식 키보드 타건음, 정답을 맞힐 때마다 팡! 터지는 묵직한 타격음.
   - **연속 콤보 시스템**: 연속 정답 시 `🔥 3 COMBO!`, `🔥 7 COMBO!`와 함께 사운드 피치가 상승하여 몰입감 극대화.
   - **스크린 쉐이크 (Screen Shake)**: 정답 시 가볍고 찰진 진동, 오답 시 경고 진동.
   - **네온 스파크 파티클**: 단어 완성 및 문장 격파 시 화면 가득 폭죽과 불꽃 파티클 폭발!

3. **스마트 취약 문장 무한 드릴 (Weakness Drill)**
   - 중간에 자주 틀리거나 헷갈리는 문장은 자동으로 취약 문장(🔥)으로 등록되어 100% 마스터할 때까지 무한 반복.

4. **풍부한 기본 프리셋 & 커스텀 지문 등록**
   - 스티브 잡스 스탠포드 졸업 축사 (영어)
   - 대한민국 헌법 전문 (법률/공시)
   - 마틴 루터 킹 목사 연설 (영어)
   - 윤동주 - 서시 (한국 명시)
   - 실전 발표/PT 오프닝 템플릿
   - 사용자가 원하는 모든 긴 글(영어 본문, 시험 서술형, 발표 대본, 법조문 등)을 자유롭게 붙여넣기 및 스마트 자동 문장 분할 지원.

---

## ⌨️ 키보드 단축키

| 키 | 동작 |
| :--- | :--- |
| `Space` | 원문 정답 확인 토글 (또는 TTS 오디오) |
| `Enter` | 완벽히 외웠음 (마스터 체크) |
| `←` / `→` | 이전 / 다음 문장 이동 |
| `1` ~ `5` | 1단계 ~ 5단계 학습 모드 즉시 전환 |
